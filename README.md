# CJC registration page

Static registration page for C.A.I.R.O Journal Club events. Open it as `https://mhosam18-max.github.io/cjc-register/?r=<web app deployment id>`.
It reads the event from the event's Apps Script web app and sends the registration there. No data is stored here.

Built from Registration.html in the private Operation-Sheet-CJC repository (external/build_page.py).
